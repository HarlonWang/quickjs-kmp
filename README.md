# quickjs-kmp

Kotlin Multiplatform binding for [QuickJS](https://github.com/bellard/quickjs) (ES2025). Android + iOS, with macOS as a debug host.

> Design stage. See [docs/decisions.md](./docs/decisions.md) and [docs/roadmap.md](./docs/roadmap.md). API mirrors [mquickjs-kmp](https://github.com/HarlonWang/mquickjs-kmp); built for [TinyUI](https://github.com/HarlonWang/tinyui) but not tied to it.
